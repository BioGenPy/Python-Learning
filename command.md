Installaion process :


| Step  | Action                    | PowerShell Command                                                 |
| ------- | --------------------------- | -------------------------------------------------------------------- |
| **1** | **Create**the environment | python -m venv .numpy_venv                                         |
| **2** | **Activate**it            | `.\.numpy_venv\Scripts\Activate.ps1                                |
| **3** | **Verify**it works        | *(You will see`(.venv)`appear at the start of your terminal line)* |
| **4** | **Deactivate**when done   | `deactivate`                                                       |
